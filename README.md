## 安装

### Codex

全局安装：

```bash
git clone https://github.com/limczhh/miuix-skill.git ~/.codex/skills/miuix
```

项目内安装：

```bash
git clone https://github.com/limczhh/miuix-skill.git .codex/skills/miuix
```

其他工具请将仓库放入对应的 Skill 目录，并确保 `SKILL.md` 位于目录根部。
